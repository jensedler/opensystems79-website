## 1. Datenschutz auf einen Blick

### Allgemeine Hinweise

Diese Webseite ist ein statisches, persönliches Blog. Es werden keine
Tracking-Cookies, keine Analyse-Tools, keine externen Schriftarten und
keine sonstigen Drittanbieter-Ressourcen zur Laufzeit eingebunden. Alle
Inhalte – inklusive Schriftarten – werden direkt vom Hostserver
ausgeliefert.

### Datenerfassung auf dieser Website

**Wer ist verantwortlich für die Datenerfassung auf dieser Website?**

Die Datenverarbeitung auf dieser Website erfolgt durch den
Websitebetreiber. Dessen Kontaktdaten finden Sie im
[Impressum](/impressum/).

**Wie erfassen wir Ihre Daten?**

Beim Besuch der Website werden vom Hostinganbieter technisch notwendige
Verbindungsdaten verarbeitet (Server-Logfiles, siehe Abschnitt 4).

## 4. Datenerfassung im Detail

### Cookies

Diese Website verwendet **keine Cookies**.

Lokal wird im Browser über `localStorage` lediglich die von Ihnen
gewählte Theme-Einstellung (auto/light/dark) gespeichert, damit die
Auswahl beim nächsten Besuch erhalten bleibt. Diese Information
verbleibt ausschließlich in Ihrem Browser und wird **nicht** an einen
Server übertragen.

### Server-Logfiles

Der Hostinganbieter (GitHub Pages, siehe Abschnitt 2) erhebt und
speichert automatisch Informationen, die Ihr Browser bei jedem Abruf
übermittelt (Browsertyp, Betriebssystem, Referrer-URL, Hostname,
Uhrzeit, IP-Adresse). Auf den Umfang und die Speicherdauer dieser
Logs hat der Betreiber dieser Website keinen direkten Einfluss.

### Externe Dienste, Tracking, Analytics

Es werden **keine externen Dienste** wie Google Fonts, Content
Delivery Networks (CDNs), Analytics-Lösungen (z. B. Google Analytics,
Matomo, Plausible), Tracking-Pixel, eingebettete Videos, Social-Media-
Plugins oder vergleichbare Drittanbieter-Ressourcen zur Laufzeit
eingebunden.

### RSS-Feed

Diese Website stellt unter `/feed.xml` einen RSS-Feed bereit. Beim
Abruf des Feeds gelten die gleichen Bedingungen wie für reguläre
Seitenaufrufe (siehe Abschnitt 2).
